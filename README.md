# 3B Indústria Fitness - Website Profissional

Site profissional da 3B Indústria Fitness, especializada em equipamentos de alta performance para academias, racks, rigs e estruturas metálicas.

## 🚀 Tecnologias

- **Next.js 14** - Framework React moderno
- **React 18** - Biblioteca UI
- **TypeScript** - Tipagem estática
- **Tailwind CSS** - Estilização utilitária
- **Cursor Customizado** - Interação visual avançada

## 📋 Seções

- **Hero Section** - Apresentação principal com imagem de fundo
- **Estatísticas** - Destaques da empresa
- **Projetos** - Produtos em destaque
- **Categorias** - Produtos organizados por tipo
- **Serviços** - Soluções oferecidas
- **Contato** - Formulário e informações de contato

## 🎨 Design

- Dark theme com acentos em laranja (#ff6a00)
- Responsive design (mobile, tablet, desktop)
- Animações suaves e interativas
- Custom cursor com efeito de blur

## 📥 Instalação

```bash
# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev

# Build para produção
npm run build
npm run start
```

## 📁 Estrutura

```
.
├── app/
│   ├── page.tsx          # Página principal
│   ├── layout.tsx        # Layout base
│   └── globals.css       # Estilos globais
├── public/
│   └── images/           # Imagens do site
├── package.json
├── tailwind.config.ts
├── tsconfig.json
└── next.config.js
```

## 🔧 Configuração

Para adicionar suas imagens, coloque-as na pasta `public/images/` e atualize os caminhos em `app/page.tsx`.
